# Multi-UAV Formation Control
At the Advanced Control Laboratory, my research spans LiDAR point cloud processing, multi-agent coordination, and experimental validation of autonomous aerial systems. My current work focuses on learning-based collision avoidance and safe coordinated flight.

### Livox Mid-360 LiDAR Flight Test
Demonstrated stable, low-speed flight around the test field with a Livox Mid-360-equipped UAV. Recorded LiDAR point clouds were visualized in RViz to evaluate sensing performance during flight.
